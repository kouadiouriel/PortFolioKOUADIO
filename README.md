# Portfolio de Kouadio uriel

Portfolio personnel en une page (one-page), en français, adapté à l'ordinateur, à la tablette et au mobile.

## Voir le site

- Site en ligne : https://adhouseofculture.netlify.app/?utm_source=snapchat&utm_medium=social#kemia
AD House of Culture · Maison de culture à Abidjan
AD House of Culture, maison de culture basée à Abidjan : concepts culturels dont le festival Kémia, concerts et showcases, consulting événementiel, production artistique.
 

- Code source : https://github.com/kouadiouriel/portfolio

## Ouvrir en local

1. Télécharger ou cloner le dépôt

2. Ouvrir `index.html` dans un navigateur

(Une connexion internet est nécessaire : Tailwind CSS et la police sont chargés par CDN.)

## Contenu

- Introduction : présentation, photo, accroche

- CV : formation, expériences, compétences

- Projets : kemia  ; level up ; site de vêtements

- Contact : formulaire et liens (e-mail, GitHub, LinkedIn)

## Technologies

HTML5, CSS3, JavaScript, Tailwind CSS

## Structure

- `index.html` : page principale

- `styles.css` : styles et couleurs

- `script.js` : thème clair/sombre, navigation

- `images/` : photo, logo et visuels des projets
