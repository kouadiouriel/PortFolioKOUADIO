# Portfolio one-page

## Ouvrir
Double-cliquez sur `index.html` (navigateur récent). Une connexion internet est nécessaire (Tailwind CSS et la police Poppins sont chargés par CDN).

## Modifier vos informations
Tout se trouve dans `index.html`. Cherchez les textes entre crochets `[...]` et remplacez-les :
- Nom, titre, formation, accroche : section `#introduction`
- Études, expériences, compétences : section `#cv`
- Projets : section `#projets` (une balise `<article>` par carte)
- E-mail, GitHub, LinkedIn : section `#contact`, le pied de page et les icônes de l'introduction
- Photo : remplacez `images/photo-placeholder.svg` (ou changez le nom dans la balise `<img>`)
- Couleurs : variables en haut de `styles.css`

(Version desktop : la partie responsive est ajoutée à l'étape 3.)
